# neo-brick-crush

`neo-brick-crush`는 BMAD 기반으로 기획, 설계, 구현을 진행하는 벽돌깨기 계열 게임 프로젝트입니다.

## 폴더 구조
- `app/`: 게임 소스 코드
- `_bmad-output/planning-artifacts/`: 게임 브리프, GDD, 아키텍처, 에픽/스토리 등 기획 산출물
- `_bmad-output/implementation-artifacts/`: 구현 관련 산출물
- `_bmad-output/test-artifacts/`: 테스트 계획 및 결과

## 시작 상태
- 프로젝트 스캐폴딩 완료
- 프로젝트별 BMAD 산출물 경로 초기화 완료
- 다음 추천 단계는 `Game Dev Studio` 흐름의 게임 브리프 작성입니다
